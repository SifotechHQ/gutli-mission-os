# Gutli Mission OS

India's Mango Revolution Platform — built by Sifotech HQ, Bradford UK.
Live: https://gutli-mission-os.vercel.app

## Features
- Zone Advisor — soil + climate analysis for 15 Indian states
- Seed Tracker — every donated seed tracked from donor to farmer
- WhatsApp Bot — full conversations in Hindi, Punjabi, Bengali
- Farmer Registration — 3-step AI soil analysis
- CSR Reports — verified impact data for corporate funders
- Trilingual UI — EN / हिंदी / ਪੰਜਾਬੀ / বাংলা

## Tech
Single HTML file. Supabase tracking. Deployed on Vercel.
